The source manager contains eight references to the testnet PoX-5 boot contract and thirteen
references to the upstream sBTC deployer. Network artifacts are generated by replacing exactly
those occurrences according to an immutable profile. A generated artifact is not production-
approved merely because its output is deterministic.

Stacks 4.0.1 is the formal node/signer launch release. Its PoX-5 source is retained beside the
4.0.0 source rather than replacing it. The reference `signer-manager.clar` source is unchanged
between the tags, so the deterministic manager lineage remains pinned to the existing 4.0.0
source/hash while network compatibility profiles select the live PoX-5 fingerprint independently.
