Signer Sidekick — screen mockups

Static UI/UX mockups for the PoX-5 pool operator control plane, built on the vendored Stacks Labs design system. Each screen is scoped to the one question it must answer (spec §12). Toggle theme and network (mainnet ↔ testnet violet) from any screen's top bar.

Build notes. Every value resolves to a vendored token in ../tokens/tokens.css — no hard-coded brand hex. The product theme layer adds --accent aliases and the [data-network="testnet"] violet remap the token file leaves to the app. Numbers carry a provenance dot: contract read-only, indexed / estimated, locally derived. These are reference mockups for the React component layer in apps/dashboard, not the app itself.
