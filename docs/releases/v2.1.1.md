## Operator changes

- Keep Overview, Pool, and Rewards available while the Stacks tip advances normally; reorgs and unverifiable anchors still fail closed.
- Focus signer-health attention on sustained, actionable local failures instead of transient validation latency, rejection-rate, or agreement signals. Wider-network API lag remains visible as context.
- Use the standard public Stacks testnet with `SIDEKICK_NETWORK=testnet`, chain ID `0x80000000`, and `https://api.testnet.hiro.so`.

## Before upgrading

No database migration is required for mainnet. Back up `sidekick.sqlite` and `gas-wallet.key` together, set `SIDEKICK_IMAGE_TAG=2.1.1`, and recreate the Sidekick container.

The retired PoX-5 testnet used a different chain identity. Testnet operators moving from chain ID `0x80000005` must start with a fresh Sidekick database and Docker volume, then prepare new wallet intents.
