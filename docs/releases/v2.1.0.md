## Operator changes

- See each manager operation as available, observe-only, or unavailable, with the reason and the matched adapter when execution is supported.
- Run the published image natively on amd64 or arm64 hosts.
- Confirm submitted transactions from canonical block evidence when the node transaction index is disabled.
- Start cleanly with Stacks Core after a host reboot, including while the node replays queued observer callbacks.
- Show the correct operator fee and keep completed prior-cycle distributions available while a later distribution is pending.
- Let password managers recognize the operator-token login field.

## Before upgrading

No database migration is required. Back up `sidekick.sqlite` and `gas-wallet.key` together, set `SIDEKICK_IMAGE_TAG=2.1.0` (container tags no longer include the Git tag's `v` prefix), and recreate the Sidekick container.
