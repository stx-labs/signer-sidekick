## Operator changes

- Run PoX-5 reward calculation, collection, distribution, and Bitcoin-payout finishing as one durable, operator-approved job.
- Review current distributions, past payments, fees, Stacks transactions, and Bitcoin sweep proofs from the rebuilt Rewards workspace.
- Keep useful reward state during indexed-API lag, with faster preparation and bounded history work for larger pools.

## Before upgrading

Back up `sidekick.sqlite` and `gas-wallet.key` together. V2 applies forward-only database migrations and removes the legacy Assist execution path. Existing installations remain observe-only; set `SIDEKICK_ENGINE_MODE=operator-run`, then create, fund, and enable the dedicated gas wallet to run reward operations.
