## Operator changes

- Start cleanly with Stacks Core after a host reboot, including when the node is replaying queued observer callbacks.
- Confirm submitted transactions from canonical block evidence when the node transaction index is disabled.
- Show the correct operator fee and keep completed prior-cycle distributions available while a later distribution is pending.
- Let password managers recognize the operator-token login field.

## Before upgrading

No configuration or database migration is required. Back up `sidekick.sqlite` and `gas-wallet.key` together, update `SIDEKICK_IMAGE_TAG` to `v2.0.1`, and recreate the Sidekick container.
